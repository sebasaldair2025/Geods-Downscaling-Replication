# Geods-Downscaling-Replication
Replicación del modelo de downscaling de precipitación GeoDS (Brenner et al.), basado en el índice de exposición topográfica (TEI). Climatología, mapas de anomalía y validación cuantil-cuantil en los Alpes (calibración, con APGD) y Groenlandia (generalización). Pasantía preprofesional EPN
